

# point_cloud_compression_test
test code for PCL and Draco Library

Draco: [Draco](https://google.github.io/draco/)

PCL: [PCL](http://pointclouds.org/)

## Usage
Run the Draco evaluation tool with a compression level (0-10) and quantization bits (1-31):
```bash
./draco_eval <compression_level> <quantization_bits>
```
